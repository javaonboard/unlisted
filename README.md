# Unlisted

Sell what you never listed.

Unlisted gives everyone a personal agent that finds buyers for things you own,
finds what you need, negotiates for you, and settles the deal with PayPal.

Work in progress for the PayPal AI Hackathon.

## Run locally

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000.
